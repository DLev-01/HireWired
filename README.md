# HireWired

## Project Description
HireWired is a job marketplace platform built with Django, designed to connect job seekers with employers in a seamless and efficient manner. The platform provides tools for posting job listings, applying for jobs, and managing user profiles.

## Features
- User authentication and authorization
- Job posting and listing
- User profiles for job seekers and employers
- Application management system for job seekers
- Search and filter options for jobs
- Administrative dashboard to manage users and listings

## Tech Stack
- **Backend**: Django
- **Frontend**: HTML, CSS, JavaScript
- **Database**: PostgreSQL
